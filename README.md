# PROGETTO_REACT_2024-25
Creazione di un’app avanzata per analizzare e interpretare i dati del sonno, trasformandoli in
informazioni utili e personalizzate per migliorare la qualità del riposo.

## ⚙️ Requisiti di versione

- **Node.js**: ^20.18.1
- **NPM** (incluso con Node.js) 

---

## 🛠️ Configurazione e Avvio Locale

1. Crea una copia della repository:
   ```bash
   git clone https://github.com/SaturnAnton/PROGETTO_REACT_2024-25.git
    cd PROGETTO_REACT_2024-25
    ```
2. Installa le dipendenze:
    ```bash
    npm install
    ```
3. Crea una build:
    ```bash
    npm run build
    ```
4. Creare una preview del progetto:
   ```bash
    npm run preview
    ```
